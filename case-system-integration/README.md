# Интеграция CRM «WebStyle» с сервисом MadeTask

**Роль:** Системный аналитик / Solution Architect
**Тип проекта:** Учебный кейс (ООО «Карпов Курсы»)
**Артефакты:** ТЗ (PDF), Модель данных (DDL), UML-диаграммы (PlantUML/PNG)

---

## 📌 О проекте

Компания «WebStyle» занимается разработкой сайтов и использует CRM для работы с заказчиками. Внешние подрядчики (дизайнеры, копирайтеры) работают через мессенджеры, а бухгалтерия вручную переводит им деньги через СБП/банк, сверяя реквизиты в Excel.

**Цель:** Спроектировать интеграцию CRM с внешним финтех-сервисом MadeTask для автоматизации создания задач, контроля их выполнения и автоматических выплат по реквизитам подрядчиков (включая криптовалюты и иностранные валюты).

## 🎯 Ключевые результаты и архитектурные решения

В ходе проектирования был проведен глубокий аудит бизнес-требований и документации API MadeTask. В финальную версию ТЗ (v2.0) заложены следующие решения:

*   **🔒 Безопасность (AppSec):** Внедрена защита от дублей транзакций (Idempotency) через заголовок `X-Idempotency-Key`, спроектировано маскирование PII (персональных данных) в логах для соответствия 152-ФЗ, составлена матрица ролей (RBAC).
*   **📊 Модель данных:** Разработана логическая модель БД (PostgreSQL) с поддержкой оптимистичных блокировок (защита от одновременного редактирования), паттерна Soft Delete и архивации финансовых документов на 5 лет (402-ФЗ).
*   **⚙️ State Machine:** Спроектирован строгий жизненный цикл задачи, включая обработку возвратов на доработку («Отклонена» -> «Ждет проверки») и статус «Ошибка оплаты» при сбоях API.
*   **🚀 DevOps & Reliability:** Пересмотрены нефункциональные требования под реалии MVP (1 сервер). Спроектирована отказоустойчивая очередь (RabbitMQ + DLQ) с гарантией доставки, настроены реалистичные SLA/RTO/RPO.
*   **⚖️ Юридическая чистота:** Добавлены требования по сбору согласий на обработку ПДн (152-ФЗ) и формированию налоговой выгрузки (XLSX) с курсами валют и ИНН.

## 🛠 Стек технологий и стандарты

В проекте описаны требования к следующему стеку:
*   **Бэкенд:** Python 3.10+ / Node.js 18+ / Java 17 (на выбор команды)
*   **База данных:** PostgreSQL 14+
*   **Очереди и кэш:** RabbitMQ (с DLQ), Redis
*   **Инфраструктура:** Docker / Docker Compose, Prometheus + Grafana (мониторинг)
*   **Стандарты:** REST API, OpenAPI 3.1, PlantUML, UML 2.5
